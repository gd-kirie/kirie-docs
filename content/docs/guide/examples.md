# Examples

The [kirie-examples repository](https://github.com/gd-kirie/kirie-examples) contains runnable Kirie projects.
Each example has its own installation and platform instructions.

| Topic | What to explore |
| --- | --- |
| Raw IPC | Text, binary, and structured data between Godot and the browser |
| CLI workflows | Development sessions, builds, exports, and device launch |
| Eventa with C# | Typed events and request/response calls through a .NET host |
| Platform | Host window controls and platform events |
| Tray and notifications | Optional plugins and native host capabilities |
| Native-hosted Godot | Godot integration inside a native host |

For a minimal starting project, use the [basic template](https://github.com/moeru-ai/kirie-templates/tree/main/templates/basic).
Follow [Getting started](./getting-started.md) to create a project from the template pinned by your CLI release.
